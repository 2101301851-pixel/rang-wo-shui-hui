## 第二章规则（格子间）

- 领导沿走廊网络巡逻，**黄色视野锥**是他能看见的范围；锥变成**红色**＝你已经暴露。
- 视线死角（背过身/停下张望扫不到你）时：
  - `空格` **趴桌睡觉**：清醒度 **−9/秒**（工作会让清醒度 +1.1/秒，必须找机会睡回来）
  - `S` **摸鱼**：涨**摸鱼值**——跟同事唠嗑 +7/s（有概率触发同事**望风**，被抓时帮
    你把领导缠住 3.5 秒）、摸鱼打游戏 +10/s、刷手机 +8/s、偷偷看盘 +9/s（血压升高，
    清醒度反而 +2/s）
- 领导看到你不在工作，有 **0.75 秒** 反应窗口按任意互动键切回工作＝惊险逃脱；
  超时被抓：睡觉 +28 清醒 / 摸鱼 +14 清醒，并扣摸鱼值，**被抓 3 次直接开除**。
- **清醒度 ≤2** 睡死过去、**≥98** 彻底清醒，都算失败。
- 撑到 **18:00** 下班，按摸鱼值评级：S ≥150（摸鱼大师）/ A ≥110 / B ≥70 / C 老实人。

## 调参入口

都写在 `index.html` 里：

- 第一章：`BAND_LO / BAND_HI`（朦胧区 40/62）、`COP_AT`（有交警的路口索引）、
  `SIT_DRAIN`（长椅打盹速率 −7）、`items` 数组（物品摆放）、
  `WORLD_LEN`（路程总长 6300）、`CUT_A / CUT_LEN`（缩短路程时删去的区段，当前 4200 起 2100 长）、
  `FAR_FAC / FAR_BASE_Y`（远景楼群视差系数 0.3 / 楼底基线 184）、`FAR_SEGS`（楼群裁切框）、
  `SHOP_SEGS`（小店裁切框）、`buildLevel` 里的 `P('shop',…)`（小店摆放位置）
- 第二章：`ACTS2`（四种摸鱼活动的速率）、`DAY_LEN`（上班时长，默认 100 秒）、
  `L2PTS / L2GRAPH`（领导巡逻的走廊节点图）、`IMG_OY2`（底图裁切位置）
- 抓捕反应窗口 0.75 秒、被抓惩罚 +28/+14 清醒：在 `update2` 里搜索 `0.75`

## 调试参数（测试用）

URL 后加参数：`?w=14`（初始清醒度）、`?x=5900`（出生位置）、`?fast=1`（三倍速）。
例如 `index.html?fast=1&x=5900` 可以快速看到第一关通关结算。
